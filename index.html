소프트웨어와 생활 · 피지컬 컴퓨팅 프로젝트

초음파 센서 기반 사각지대 보행자 충돌 예방 시스템

ㄱ자 복도의 양쪽 통로에서 물체가 동시에 접근하면 경고등과 부저가 작동하는 가상 시뮬레이션입니다.

복도 모형 · 접근 상황

정상 상태 · 안전 양쪽 동시 접근이 감지되지 않았습니다.

센서와 출력 장치

초음파 센서 A14 cm
초음파 센서 B14 cm
LED A
LED B
부저 OFF
판단 조건: 0 < A ≤ 8cm AND 0 < B ≤ 8cm
FALSE → 경고 OFF

직접 체험하기

3cm기준 8cm18cm
3cm기준 8cm18cm

8cm는 우드락 축소 모형을 위한 시연 기준입니다. 한쪽만 가까우면 경고하지 않고, 두 센서가 모두 8cm 이하일 때만 경고합니다.

아두이노 회로 연결표
부품Arduino UNO
센서 A TRIG/ECHOD2 / D3
센서 B TRIG/ECHOD4 / D5
두 센서 전원5V / GND
LED A / LED BD8 / D9 (각 220Ω 저항)
능동 부저 신호D10
부저 전원5V / GND
